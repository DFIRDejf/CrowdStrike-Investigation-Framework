# Contributing to CrowdStrike CQL Framework

Use one pull request per logical query group. Follow [query template](templates/QUERY_TEMPLATE.md) and [validation checklist](20-Query-Optimization-and-QA/README.md). Distinguish user-tested content from candidate and community adaptations. Never upload company-sensitive indicators, account identifiers, IP allowlists, or logs. Cite external source links without reproducing full third-party tutorials.
